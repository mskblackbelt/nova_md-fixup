# Typography and Emphasis

Straight "double quotes" and 'single quotes' that smart-quote handling should
convert. An ellipsis written as three dots... and an em dash written as -- two
hyphens, plus a range of 10--20 written the same way.

This paragraph mixes **bold text** with __other bold text__, and *italic text*
with _other italic text_, so the Reverse Emphasis setting has something to
normalize in both directions.
